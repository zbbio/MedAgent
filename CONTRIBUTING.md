# Contributing

1. Create a branch from the default branch.
2. Keep credentials and private corpora outside the repository.
3. Install development dependencies with
   `python -m pip install -r requirements-dev.lock`.
4. Run `python -m pytest -q` and `npm --prefix frontend run build`.
5. Describe behavior and security changes in the pull request.

Contributions are submitted under the Apache License 2.0 unless explicitly
stated otherwise. Do not contribute copyrighted medical text or indexes.
